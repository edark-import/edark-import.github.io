# eDark — Plataforma de Servicios Tecnológicos & Soluciones TI

Versión moderna en **Next.js 16 + TypeScript + Tailwind CSS** preparada para despliegue en **Vercel**.

> La versión histórica multipágina en HTML/Express/Flask se conserva intacta en la rama `legacy-html`.

## Servicios Incluidos

1. **Consultoría Tecnológica** (`/servicios/consultoria`)
2. **Asesoramiento Empresarial B2B** (`/servicios/asesoramiento-empresa`)
3. **Asesoramiento para el Hogar** (`/servicios/asesoramiento-hogar`)
4. **Soporte Técnico Inmediato** (`/servicios/soporte`)
5. **Mantenimiento y Reparación** (`/servicios/mantenimiento`)
6. **Armado de PC Personalizada** (`/pc-personalizada`)
7. **Reciclaje Tecnológico R2v3** (`/servicios/recicla`)

## Desarrollo Local

```bash
npm install
npm run dev
```

## Verificación de Calidad

```bash
npm run lint
npm run typecheck
npm run build
```
